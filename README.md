# CENTER FOR LIVELIHOOD & DEVELOPMENT (CLD KENYA)
### Official Website & Digital Platform (Nairobi, Kenya)

**Center for Livelihood & Development (CLD Kenya)** is a registered non-governmental organization headquartered in Upper Hill, Nairobi, Kenya. This repository contains the complete, production-ready, mobile-responsive website.

---

## 🌟 Key Highlights & Features

1. **Kenyan NGO Identity & Branding**
   - Official brand emblem & typography vector (`assets/logo.svg`).
   - Kenyan NGO Coordination Board regulatory badges (OP.218/051/12).
   - Color palette reflecting Kenya's agricultural resilience (Deep Forest Green, Harvest Amber Gold, Clean Water Blue).

2. **Mobile-First & Fully Responsive**
   - Modern sliding drawer navigation for mobile devices and tablets.
   - Fluid typography, touch-friendly CTA buttons, and interactive cards.

3. **M-PESA & Multi-Channel Giving Integration**
   - **Interactive M-Pesa STK Push Simulator:** Users can input their Safaricom phone number to simulate prompt delivery, receive live feedback, and view an instant digital tax receipt.
   - **Manual Paybill & Till Numbers:** Quick one-click clipboard copying for Paybill `522522` (Acc: `CLD-KENYA`) and Till `981245`.
   - **Bank Wire Transfer:** Complete KES and Foreign Currency (USD/EUR) details for Equity Bank Kenya and KCB Bank Kenya.

4. **Strategic Pillars & Programs**
   - Climate-Smart Agriculture & Urban Sack Farming (Kibera, Mathare, Mukuru)
   - Women & Youth Micro-Enterprise Revolving Seed Fund
   - Clean Water (WASH), Solar Boreholes & Renewable Energy
   - Youth Digital Academy & Vocational Innovation
   - Maternal Health, Nutrition & Grassroots Advocacy

5. **Human Impact & Accountability**
   - Animated statistics counters (48,500+ Livelihoods Transformed, 18 Counties, 140+ Enterprises).
   - Real beneficiary case studies and voices of change.
   - Financial stewardship charter (84% Programs, 10% M&E, 6% Ops).

6. **Interactive Forms & Engagement**
   - Inquiry & contact form with instant validation.
   - Volunteer & mentor application portal.
   - Newsletter subscription toasts.
   - Interactive FAQ accordion.

## 🚀 How to Run & Preview

### Option 1: Direct File Opening (No Installation Needed)
Double-click [index.html](file:///C:/Users/ENG.%20KIPTOO/.gemini/antigravity/scratch/center-for-livelihood-development/index.html) to open the website directly in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### Option 2: Local HTTP Server (PowerShell / Node.js)
In PowerShell, navigate to the folder and launch a local web server:
```powershell
# Using Python:
python -m http.server 8080

# Or using npx:
npx serve .
```
Then visit `http://localhost:8080` in your browser.
